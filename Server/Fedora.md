# Fedora Server

## 1. Device Overview

| Parameter | Value |
|---|---|
| Operating System | Fedora Workstation Live 44 |
| Role | Infrastructure Services Server |
| Hostname | To be documented |
| LAN Interface | ens224 |
| LAN IP Address | 10.10.20.50/24 |
| LAN VLAN | VLAN 20 - SERVERS |
| NAT Interface | ens160 |
| NAT IP Address | 192.168.8.131 |
| Default Gateway | 192.168.8.2 |

## 2. Network Configuration

The server uses two network interfaces.

| Interface | IP Address | Purpose |
|---|---|---|
| ens160 | 192.168.8.131 | Internet connectivity through NAT |
| ens224 | 10.10.20.50/24 | Internal laboratory network |

The internal interface is connected to VLAN 20 (SERVERS).

The server uses the internal network gateway `10.10.20.254`.

## 3. Network Services

The Fedora server provides several infrastructure services for the laboratory.

### 3.1 DHCP Server

- DHCP implementation: Kea DHCP
- Provides IP address configuration to internal network clients.
- DHCP service configuration and address pools to be documented.

### 3.2 DNS Server

- DNS implementation: BIND
- Internal DNS domain: `azienda.local`
- Forward DNS zone configured.
- Reverse DNS zone configured.

### 3.3 Syslog Server

- Implementation: rsyslog
- Receives logs from network devices through UDP port 514.
- Device logs are stored in separate files.

Network devices configured to send logs to the Fedora server include:

- R1
- R2
- R3
- SW1
- SW2
- SW3

### 3.4 NFS Server

The server provides network file sharing through NFS.

Exported directory:

`/srv/nas`

Access policy:

| Network | Access |
|---|---|
| VLAN 20 - SERVERS | Read/Write |
| VLAN 10 - UTENTI | Read Only |
| Other networks | Not authorized |

NFS mount and permission tests are pending documentation.

### 3.5 SSH Server

SSH provides remote administration of the Fedora server.

SSH configuration and access restrictions to be documented.

### 3.6 Fail2ban

Fail2ban is configured to protect SSH against repeated authentication failures.

| Parameter | Value |
|---|---|
| Protected Service | SSH |
| Max Retry | 3 |
| Find Time | 300 seconds |
| Ban Time | 600 seconds |

The SSH jail monitors failed authentication attempts and temporarily bans clients exceeding the configured retry limit.

## 4. System Logging and Monitoring

The Fedora server centralizes Syslog messages generated by the network infrastructure.

Each network device sends its logs to:

`10.10.20.50`

The server stores logs in separate files for easier troubleshooting and analysis.

## 5. Network Integration

The Fedora server is connected to the internal SERVERS VLAN.

Its services support the operation and management of the laboratory:

- DHCP for client address assignment.
- DNS for internal name resolution.
- Syslog for centralized logging.
- NFS for network file sharing.
- SSH for remote administration.
- Fail2ban for SSH protection.

## 6. Security Configuration

Security mechanisms implemented or planned include:

- SSH remote administration.
- Fail2ban SSH protection.
- NFS access restrictions based on network.
- VLAN-based network segmentation.
- Firewall policies enforced by OPNsense.
