# R2 – Router Configuration

## 1. Device Overview

| Parameter | Value |
|---|---|
| Hostname | R2 |
| IOS version | 15.9 |
| Router ID | 2.2.2.2 |
| Loopback0 | 2.2.2.2/32 |
| OSPF process / area | 1 / area 0 |
| Role | Transit router, default route propagation |

R2 is the transit router between the internal OSPF network and the OPNsense firewall. It keeps a static default route towards the firewall and advertises it to the other routers through OSPF. It has no VLAN sub-interfaces, no ACLs and no HSRP: it does not serve any host directly.

## 3. Configuration Summary

| Feature | Implementation |
|---|---|
| Dynamic Routing | OSPF Area 0 |
| Router ID | 2.2.2.2 |
| OSPF Authentication | MD5 on R1 transit link |
| Default Route | Static route toward OPNsense |
| Default Route Propagation | OSPF `default-information originate` |
| Firewall Connection | 10.10.250.2/30 |
| Syslog | Fedora – 10.10.20.50 |
| Time Synchronization | NTP server 1.1.1.1 |
| Remote Management | SSH v2 |

## 4. Routing and Firewall Integration

R2 uses a static default route pointing to the OPNsense firewall:

- R2 GigabitEthernet0/1: `10.10.250.2/30`
- OPNsense LAN: `10.10.250.1/30`
- Default gateway: `10.10.250.1`

The command `default-information originate` allows R2 to advertise the default route through OSPF to the internal network.

Only GigabitEthernet0/0 is configured as a non-passive OSPF interface. The firewall-facing interface is not part of the OSPF process, so no routing protocol packets are sent to OPNsense and the `10.10.250.0/30` network is not advertised to the other routers.


## 5. Notes

- R2 has a single connection to the internal network, the link to R1. If R1 fails, R2 and the firewall are cut off from the VLANs, even though R3 takes over as the HSRP gateway.
- The console and auxiliary lines have `privilege level 15` and no login, and `exec-timeout 0 0` is set on all lines. These are lab-only settings.
- Passwords and cryptographic keys have been redacted from this public documentation.
