# R1 – Router Configuration

## 1. Device Overview

| Parameter | Value |
|---|---|
| Hostname | R1 |
| IOS version | 15.9 |
| Router ID | 1.1.1.1 |
| Loopback0 | 1.1.1.1/32 |
| OSPF process / area | 1 / area 0 |
| HSRP role | Primary (active) router for VLANs 10, 20, 30 and 99 |
| Role | Inter-VLAN routing, HSRP, OSPF, DHCP relay, NTP server |

R1 provides inter-VLAN routing through router-on-a-stick, participates in OSPF area 0, acts as the primary HSRP router for the configured VLANs and is the NTP server of the lab. It also applies the access lists that control what users and guests can reach.

## 2. Complete Configuration

The following configuration is based on the actual `show running-config` output.

```cisco
!

! SYSTEM CONFIGURATION
! ==============================
!

service password-encryption
!

!
logging buffered 16384 informational
enable secret 9 <REDACTED>
!
no aaa new-model
!
clock timezone CET 1 0
clock summer-time CEST recurring last Sun Mar 2:00 last Sun Oct 3:00
!
no ip icmp rate-limit unreachable
no ip domain lookup
ip domain name homelab
ip cef
no ipv6 cef
!
username admin privilege 15 secret 9 <REDACTED>
!
no cdp log mismatch duplex
ip tcp synwait-time 5

! ==============================

interface Loopback0
 ip address 1.1.1.1 255.255.255.255

! ==============================
!
interface GigabitEthernet0/0

 speed auto

!
! VLAN 10 - UTENTI
!
interface GigabitEthernet0/0.10
```

## 3. Configuration Summary

| Feature | Implementation |
|---|---|
| Inter-VLAN Routing | Router-on-a-Stick |
| First Hop Redundancy | HSRP |
| Dynamic Routing | OSPF Area 0 |
| OSPF Authentication | MD5 |
| DHCP Relay | Fedora server – 10.10.20.50 |
| Traffic Filtering | Extended ACLs |
| Centralized Logging | Syslog |
| Time Synchronization | NTP |
| Remote Management | SSH v2 |

## 4. Notes

- The console and auxiliary lines have privilege level 15 and no login, and exec-timeout 0 0 is set on all lines. These are lab-only settings.
- OSPF is passive by default; the three physical transit interfaces are explicitly non-passive.
- HSRP has no authentication and no interface tracking: if the link from R1 towards R2 fails, R1 stays active.
- Syslog messages are sent to Fedora at 10.10.20.50 using Loopback0 as the source interface.
- Passwords and cryptographic keys have been redacted from this public documentation.
