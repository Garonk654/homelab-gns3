# R3 – Router Configuration

## 1. Device Overview

| Parameter | Value |
|---|---|
| Hostname | R3 |
| IOS version | 15.9 |
| Router ID | 3.3.3.3 |
| Loopback0 | 3.3.3.3/32 |
| OSPF process / area | 1 / area 0 |
| HSRP role | Standby router for VLANs 10, 20, 30 and 99 |
| Role | Inter-VLAN routing, HSRP, OSPF, DHCP relay |

R3 provides inter-VLAN routing through router-on-a-stick and participates in OSPF area 0. It is the secondary HSRP router: it provides gateway redundancy alongside R1 and becomes the active gateway of the VLANs if R1 fails. It applies the same access lists as R1.

## 3. Configuration Summary

| Feature | Implementation |
|---|---|
| Inter-VLAN Routing | Router-on-a-Stick |
| First Hop Redundancy | HSRP |
| Dynamic Routing | OSPF Area 0 |
| OSPF Authentication | MD5 on R1 transit link |
| DHCP Relay | Fedora – 10.10.20.50 |
| Traffic Filtering | Extended ACLs |
| Centralized Logging | Syslog |
| Time Synchronization | NTP from R1 |
| Remote Management | SSH v2 |

## 4. HSRP Redundancy

R3 provides gateway redundancy alongside R1.

- R3 uses the `.2` address in each VLAN.
- The virtual gateway addresses end in `.254`.
- HSRP preemption is enabled on all four VLANs.
- R1 has an explicitly configured priority of 110.
- R3 does not have an explicitly configured priority in the supplied configuration.

## 5. Notes

- R3 has a single connection to the other routers, the link to R1. If R1 fails, R3 becomes the active gateway and keeps routing between the VLANs, but it loses its path to R2 and the firewall, so the internet is not reachable.
- The console and auxiliary lines have `privilege level 15` and no login, and `exec-timeout 0 0` is set on all lines. These are lab-only settings.
- No login banner is configured on R3.
- Passwords and cryptographic keys have been redacted from this public documentation.
